## Decisiones de implementación (juicio, con racional — desviaciones del mockup documentadas)

1. **Sin `SessionShell` compartido todavía.** `/estudiar/:id` monta como ruta suelta (sin layout route); `Story.tsx` renderiza su propio `.m3-app`. Un layout con un solo consumidor es abstracción prematura — se extrae en F2.3 cuando Repaso lo comparta.
2. **StoryFinish interino en `kapp/kframe` propio (sin Masthead).** `.m3-app` (overflow:hidden) rompería el scroll del quiz de 1437 líneas. Al terminar la lectura, Story envuelve `<StoryFinish/>` en `<div className="kapp"><div className="kframe">` — reproduce el contenedor actual menos el Masthead (que la spec retira en F2). F2.4 lo re-viste de verdad.
3. **`--fscale` = preferencia de usuario × escalón automático.** La preferencia muerta (`useFontScale`, 0.85-1.3) revive multiplicada por el escalón de la spec (1 → 0.92 → 0.85, piso 0.85). El escalón se decide por longitud efectiva (`chars × userScale`) con umbrales 170/220 — deterministas y testeables sin DOM; se validan contra contenido real en Task 7 y se ajustan ahí si hace falta (test + impl juntos). El clamp CSS de 7 líneas queda como último recurso para outliers.
4. **El control de velocidad sobrevive en el `estadoK`.** El dock del mockup no trae el pill de velocidad, pero `cycleSpeed`/`rate` son maquinaria existente y matarlos perdería una función. Resolución: cuando `playing`, el texto del estadoK ("K lee" / "K lee · despacio") es un botón que cicla la velocidad (`aria-label` = `story.sentence.speedAria`). Cero chrome nuevo; el string de la spec ("K lee · despacio") aparece exactamente cuando `rate < 1`.
5. **`micLevel` sobrevive en el estadoK.** El medidor en vivo (#120) hoy guía con "Acércate/Aléjate". En v4: grabando, el estadoK muestra `● Te escucho…` (nivel ok/silent), `● Acércate` (quiet), `● Aléjate` (loud) — claves existentes. Cero chrome nuevo.
6. **La señal por token se conserva.** El mockup (demo) no colorea tokens, pero perder el subrayado good/ok/bad mataría el valor visible del scoring (#22/#120). Los `m3-w` llevan `data-score` (feedback, y `liveBands` mientras graba) con las 3 reglas de color legacy porteadas a `mobile3.css`. Desviación documentada: señal conservada.
7. **`m3-w` son `<button>`, no `<span onClick>`.** Coherente con el pase a11y de F2.0; reset mínimo en CSS (`font:inherit;background:none;border:0`). Palabras sin match clickeable se renderizan como `<span>` plano.
8. **Se caen del skin** (siguen vivos en el hook/teclado): waveform + tiempos, pill de 16 barras, panel de score /100 + leyenda de conteos, botón "Escuchar a Klara" del feedback (re-escuchar = "Otra vez" → dock → play; o Space), hints de teclado visibles. El teclado completo sigue funcionando (vive en el hook).
9. **Acciones sobre `pronError`:** "Otra vez" → `cancelRecording()` (limpia el error, vuelve el dock; coherente con el modelo de retry del hook que NO auto-graba); "Continuar →" → `goNext()` (ya limpia vía `cancelRecording` interno). Cero cambios al hook.
10. **Nombres de archivo se conservan** (`Story.tsx`, `SentenceView.tsx`): renombrar es churn de historia sin valor; F-futuras deciden.
11. **`state.from` genérico:** las entradas pasan `{ state: { from: <pathname actual> } }`; Estudiar sale a `location.state?.from ?? "/"`. Hoy toda salida va a `/` — el fallback preserva el comportamiento exacto donde no se pase state.

```ts
/**
 * Escalón automático de la oración del teleprompter (spec F2 §5.1):
 * 1 → 0.92 → 0.85, piso 0.85. La longitud efectiva pondera la escala de
 * fuente elegida por el usuario; el line-clamp:7 del CSS queda como último
 * recurso para outliers del LLM. Umbrales calibrados a ~25-30 chars/línea
 * en 430px (validados contra contenido real en el PR).
 */
export function autoFscaleStep(target: string, userScale: number): 1 | 0.92 | 0.85 {
  const efectiva = target.length * userScale;
  if (efectiva <= 170) return 1;
  if (efectiva <= 220) return 0.92;
  return 0.85;
}
```

```ts
import type { MicLevel } from "./silenceDetector";

export type DockStatus =
  | { kind: "escuchando"; nivel: MicLevel }
  | { kind: "evaluando" }
  | { kind: "leyendo"; despacio: boolean }
  | null;

/** Estado de la línea `estadoK` del dock de Estudiar. Precedencia: grabar > evaluar > leer. */
export function dockStatus(o: {
  playing: boolean;
  recording: boolean;
  evaluating: boolean;
  micLevel: MicLevel;
  rate: number;
}): DockStatus {
  if (o.recording) return { kind: "escuchando", nivel: o.micLevel };
  if (o.evaluating) return { kind: "evaluando" };
  if (o.playing) return { kind: "leyendo", despacio: o.rate < 1 };
  return null;
}
```

```tsx
                else if (breakdownEntry && onBreakdownTap) onBreakdownTap(breakdownEntry, key, e.currentTarget);
              }}
            >
              {tok.text}
            </button>
          );
        })}
      </p>
      <p className="m3-gloss" key={`g${index}`}>{sentence.native}</p>
    </div>
    {pronError || showFeedback ? (
      <div className="m3-fb">
        {pronError ? (
          <>
            <p className="nota" role="alert">{t(`pron.error.${pronError.kind}`)}</p>
            <div className="acciones">
              <button className="k-btn k-btn--ghost" onClick={onErrorDismiss}>{t("story.sentence.feedback.retry")}</button>
              <button className="k-btn" onClick={onNext}>{t("story.step.next")} <span className="arrow" aria-hidden="true">→</span></button>
            </div>
          </>
        ) : (
          <>
            <p className="nota">
              {t(`story.sentence.verdict.${verdictKey}`)}
              {badWordTip && <> {t("story.sentence.feedback.tipPrefix")} <em>{badWordTip.display}</em>.</>}
              {badWordTip?.tip && <> {badWordTip.tip}</>}
              {diagnosing && !badWordTip?.tip && <> {t("story.sentence.feedback.diagnosing")}</>}

            </div>
          </>
        )}
      </div>
    ) : (
      <div className="m3-dock">
        <div className="estadoK">
          {status?.kind === "escuchando" && (
            <span className="rec" role="status"><span aria-hidden="true">● </span>{t(nivelKey(status.nivel))}</span>
          )}
          {status?.kind === "evaluando" && <span role="status">{t("estudiar.estadoK.evaluando")}</span>}
          {status?.kind === "leyendo" && (
            <button onClick={onCycleSpeed} aria-label={t("story.sentence.speedAria", { rate })}>
              {t(status.despacio ? "estudiar.estadoK.leeDespacio" : "estudiar.estadoK.lee")}
            </button>
          )}
        </div>
        <div className="fila">
          <button className="m3-rbtn step" aria-label={t("story.step.prev")} disabled={index === 0} onClick={onPrev}>←</button>
          <button className="m3-rbtn play" aria-label={playing ? t("story.sentence.pauseAria") : t("story.sentence.playAria")} onClick={onPlayPause}>
            {playing ? <IcPause /> : <IcPlay />}
          </button>
          <button
            className="m3-rbtn mic"
            data-on={recording ? "true" : "false"}
            aria-label={recording ? t("story.sentence.micAriaRecording") : t("story.sentence.micAria")}
            onClick={() => (recording ? void onRecordStop() : void onRecordStart())}
          >
            <IcMic />
          </button>
          <button className="m3-rbtn step" aria-label={index < total - 1 ? t("story.step.next") : t("story.step.finish")} onClick={onNext}>→</button>
        </div>
      </div>
    )}
  </>
);
```
